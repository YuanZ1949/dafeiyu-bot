# Spike S2–S7：opencode v2.0.18 的 API 形状、单位、权限与隔离

- 日期：2026-10-24
- 实例 A（默认全局配置）：`serve --port 24399`，cwd=`%TEMP%\opencode\probe-s1`
- 实例 B（隔离配置）：`XDG_CONFIG_HOME=%TEMP%\opencode\probe-s6\config` + `OPENCODE_CONFIG=` 置空，`serve --port 24398`
- 鉴权：两实例都要求 Basic（用户名 `opencode`，密码来自环境变量 `OPENCODE_SERVER_PASSWORD`）；**隔离配置不会关掉鉴权**，因为密码来自环境变量而不是配置文件。

| ID | 结论 | 证据 | 对实现的影响 |
| --- | --- | --- | --- |
| S2a | `GET /api/session/{id}/message` 默认**倒序**（新→旧）；`?order=asc` **可用**；`?type=assistant` 可用；`?limit=5` 生效 | 同一会话：默认 `types=[idle,assistant,assistant,user]`，`order=asc` 后 `types=[user,assistant,assistant,idle]` | 结束判据/取批都不依赖服务端顺序；客户端仍按 `time.created` 升序排（服务端顺序变了也不炸） |
| S2b | `time.created` 单位是**毫秒** | `created=1792855180151`（≈ 2026 年），`time.time()` ≈ 1.79e9（秒），差 3 个数量级 | 窗口比较一律用服务端单位；`until` 取本轮 `max(time.created)`，**不要**用 `time.time()` |
| S2c | `GET /api/session/{id}/context` 可用（200，返回 `data` 数组，元素带 `text`） | 实测 200 | 轮换时可用它取上下文长度；但按计划仍以 `tokens` 记账为主 |
| S2d | `POST /api/experimental/session/{id}/wait` 可用：会话空闲时立即 204 | 实测 204 | **本轮结束判据首选**：prompt → `wait` → 再读 message |
| S2e | `DELETE /api/session/{id}` 可用 | 204；随后 `GET .../message` 返回 404 | `forget()` 真删远端 session 可行；404 已被 `_UnknownSession` 覆盖 |
| S3 | 消息类型至少包含 `user` / `assistant` / `idle` | `types=[idle,assistant,user]` | 审计白名单必须是 `{user, assistant, idle}`；只认 `user+assistant` 会每轮误判 `idle` |
| S4a | 工作区内 `read` 放行：`data/bot-workspace/probe.md` → `completed` | `input={"path":"data/bot-workspace/probe.md"}`，`output="Read file ... lines 1-2"` | 工作区授权写法正确（`read` + `data/bot-workspace/**`） |
| S4b | 工作区外 `read` 被拒：项目根目录 → `state.status="error"`，`state.error.type="permission.rejected"`，`message="Permission denied: read"` | 两次实测 | 拒绝是 **tool error**，不是异常；模型会自己换个路径再试一次（导致多一步、耗时翻倍） |
| S4c | `shell` 直接被移出工具集：模型输出 `"shell tool unavailable in this environment", "available_tools":["edit","read","webfetch","write"]` | 实测 | 通配 deny 生效；`shell` 连试都试不了，这是我们要的「不开 shell」 |
| S4d | `glob` 同样不在工具集里，模型退化成 `read` 目录 → 被拒 | 实测（该轮耗时 121s：两次被拒 + 重试） | 不给 `glob`/`grep` 是对的；但**拒绝要快**，否则一轮能拖 2 分钟（Task 7 的 240s 超时够用） |
| S4e | `.env` 被**全局 oceanus 插件**的「秘密文件守卫」拦下，而不是 permission | `state.error.message="[oceanus] 秘密文件守卫…"` | 权限不是唯一防线；隔离（S6）能顺带去掉这层全局插件 |
| S5 | token 在每个 assistant 消息的 `tokens` 上：`{input, output, reasoning, cache:{read,write}}`，**每步独立** | 工具步 `input=2433,output=58`；文本步 `input=231,output=11,cache.read=2432` | `_usage()` 累加本轮所有 assistant 的 `input`/`output`；`cache.read` 单独记，不进 input |
| S6a | 默认配置下项目里能看见 **16 个 agent**（15 个全局 + 1 个项目探针） | `GET /api/agent` → `['oceanus','general','explore','compaction','title','summary','Tamako','sisyphus','prometheus','explorer','librarian','oracle','designer','fixer','observer','probe']` | 全局 agent 会漏进 bot 的 session 所在项目 —— 这是「E（外来消息）」最可能的入口面 |
| S6b | 隔离配置下同一接口只剩 **0 个全局 agent**，项目 agent 仍可正常建 session 并回答 | 实例 B：`agents count=0`，`POST /api/session {agent:"probe"}` → 200，prompt 后返回 `{"ok": true}` | 隔离**可做**：`XDG_CONFIG_HOME` 指向独立目录 + 清空 `OPENCODE_CONFIG`；代价是要把业务需要的 provider/模型配置复制过去 |
| S6c | 隔离后**provider 凭据仍然可用**（无需复制 `auth.json`） | 实例 B 正常返回文本 | 因为凭据在 data 目录（XDG_DATA_HOME），不在 config 目录 |
| S7 | `steps: 4` 下模型能只吐一行纯 JSON，无围栏、无前后缀 | 两次实测：`{"ok": true, "title": null}`、`{"ok": true}`，`json.loads` 均成功 | 输出协议稳定；但**不要用 `parse_brain_reply` 判定**（它会 salvage 任意文本，判不出问题），验收用裸 `json.loads` |

## 对实现计划的修正（必须落进代码，勿再猜）

1. **`_ask` 的结束判据**：`prompt` → `POST /api/experimental/session/{id}/wait`（204）→ 读 message → 取「本轮内最后一条带 text 的 assistant」。不要用「最后一条 assistant 有 completed」——工具步那条也是 completed。
2. **工具名读 `part["name"]`**，不读 `part["tool"]`；`on_tool` 只在 `name == "webfetch"` 且 `state.status in {"pending","running","completed"}` 的首次命中时触发一次。
3. **审计白名单 = `{user, assistant, idle}`**；只有 `type` 不在白名单，或 `type == "user"` 且 `created` 不在本轮窗口内，才算外来消息。
4. **窗口单位 = 服务端 `time.created`（毫秒）**；`since` 取本轮 user 消息的 `created - 1000`（1 秒容差），`until` 取本轮结束时的 `max(created)`；**禁止**与 `time.time()` 混比。
5. **`_usage()` 取 `tokens.input` / `tokens.output`**，`cache.read` 忽略；缺失返回 `(0,0)`。
6. **隔离方案**：`XDG_CONFIG_HOME` → 独立目录，`OPENCODE_CONFIG` 清空，把 `opencode.jsonc` 里业务需要的段（provider/model/agent 之外的）复制过去；不需要复制 `auth.json`。
7. **拒绝是 tool error 不是异常**：模型会重试一次，单个「被拒 + 重试」轮次可达 121 秒 —— 240s 超时是必要的，不要收紧。
